Park theme pictogram design

Back

A set of four pictograms, each representing a different outdoor park activity (chilling, picnicking, horseback riding, and frisbee playing), designed to function both statically and in motion. Each symbol was 3D-modeled in Blender and rendered with flat graphic shading to balance visual clarity with a playful personality.
